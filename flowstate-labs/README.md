# Flowstate Labs — Landing Page

Static landing page for Flowstate Labs: calm, considered software that makes everyday life easier.

## Structure

- `index.html` — page markup (hero, app directory, approach, email signup)
- `styles.css` — design system and all styling
- `script.js` — frosted nav on scroll, reveal animations, signup form

## Running locally

No build step needed. Either open `index.html` directly, or serve it:

```bash
python3 -m http.server 5173
```

Then visit http://localhost:5173.
