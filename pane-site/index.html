Windows apps that
behave like Mac apps.

Pane wraps a Windows program into an ordinary Mac app. It sits in Applications, opens from Spotlight, keeps a place in the Dock, and saves to your own Desktop, Documents and Downloads.

There's no virtual machine and no copy of Windows running underneath. Just the program you needed, on the Mac you already have.

In development · for macOS 14.6 and later · get one email when it ships

01

Open it the way you open anything.

Each program becomes its own .app with its own icon. Search for it in Spotlight, pin it in the Dock, drag it to the Trash when you're done. Its settings and add-ons live inside the app, so they leave with it.

02

Save, and it's in your Documents.

The program's Desktop, Documents and Downloads are your Mac's real folders. Files show up in Finder straight away, ready for AirDrop, iCloud Drive or Time Machine. Nothing is hidden on a virtual drive.

03

No second computer inside your computer.

Virtual machines boot all of Windows to run one program, and ask for a licence, gigabytes of memory and your battery in return. Pane is built on Wine, which runs the program directly on macOS. It starts like an app because it is one.

Details

Runs on
macOS 14.6 Sonoma or later. Apple silicon and Intel. Apple silicon Macs use Rosetta 2, which macOS installs when first asked.
Graphics
DirectX 9 through 12, translated to Metal. Apple's D3DMetal handles DirectX 11 and 12 on Apple silicon; DXMT, DXVK and WineD3D cover the rest.
Installing a program
Point Pane at a Windows installer (.exe or .msi) or a program folder. It builds the Mac app around it.
Your files
Desktop, Documents and Downloads are shared with your Mac. Everything stays on your machine — no account, no cloud.
Built on
Wine and the Wineskin project, with LGPL components published as source.
Availability
In development. One email when it ships, nothing else.

Questions

Will every Windows program work?

No. Most everyday programs and many games do. Anything that needs kernel-level anti-cheat or a special hardware driver usually won't.

Do I need to buy Windows?

No. Pane doesn't run Windows, so there's nothing to license. You only need the program itself.

My antivirus flagged a file.

Programs built for Wine sometimes trip antivirus heuristics; it's a known false positive across Wine-based tools. Only download Pane from this site.
